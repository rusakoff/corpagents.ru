05 / Документы по заказуCA • 06

Документы по заказу

ИИ извлекает данные из вложений и связывает файлы с нужной заявкой. Сотрудник проверяет распознавание и расхождения.

01Прочитать вложения

Excel, PDF, сканы и фото упаковочных листов из почты или выбранного мессенджера.

Нечитаемые и сомнительные поля агент отмечает для проверки.
02Сверить с заказом

Номер заказа, клиент, маршрут, вес и число мест. Для извлечённых данных сохраняем источник.

Если заказ нельзя определить однозначно, его выбирает сотрудник.
03Собрать комплект

Документы по заявке, закрывающие и материалы рекламации доступны в карточке заказа.

Сотрудник проверяет полноту. Решение по рекламации принимает ответственный.
На пилоте согласуем один вид документов. Проверяем точность полей, привязку к заказу и время обработки.
Состав комплекта и правила проверки определяем по вашему процессу06 / 13
