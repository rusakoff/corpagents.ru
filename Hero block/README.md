# Corp Agents — готовый hero-блок

**Что внутри:** полноценная векторная/HTML-иллюстрация с живым интерфейсом, адаптивный CSS, меню и вкладки, голубой объёмный фон, плавающие иконки интеграций. Всё работает без сборщика, сторонних библиотек, CDN, картинок и загрузки шрифтов.

## Вставить блок в уже существующую страницу (лучший вариант)

**`hero-embed.html`** — готовый HTML-фрагмент. Скопируйте содержимое файла в нужное место вашей HTML-страницы. CSS и JS уже внутри, никаких отдельных файлов не требуется. Если сайт уже имеет собственную шапку, удалите из фрагмента секцию `<header class="ca-header">…</header>`.

На странице нужен стандартный `<meta name="viewport" content="width=device-width, initial-scale=1">`.

## Самый быстрый способ открыть как отдельную страницу

**`hero-single-file.html`** — один файл с уже встроенными CSS и JS. Откройте в браузере; чтобы вставить в существующий сайт, скопируйте `<div class="ca-site">…</div>`, блок `<style>` и блок `<script>`. На вашей странице должен быть задан `<meta name="viewport" content="width=device-width, initial-scale=1">`.

## Раздельные файлы

1. Подключите `styles.css` в `<head>` сайта (или скопируйте в общую таблицу стилей).
2. Поместите весь `<div class="ca-site">…</div>` из `index.html` там, где должен появиться блок.
3. Подключите `script.js` в конце `body` (или с `defer`).
4. Можно просто загрузить `index.html`, `styles.css` и `script.js` в одну папку на сервер: `index.html` откроется без сборки.

## Ссылки — обязательно заменить под свой сайт

В демо стоят нейтральные якоря-заглушки. Перед публикацией обновите `href`:

- `#solutions` — страница или раздел с решениями (кнопка «Найти свою задачу»).
- `#pilot` — страница с этапами пилота («Как устроен пилот», пункт меню «Как работаем»).
- `#contacts` — форма связи или контакты («Обсудить пилот»).
- `#about`, `#cases`, `#articles`, `#faq` — соответствующие разделы сайта.
- `#ca-top` — ссылка с логотипа на верхнюю часть блока.

Сейчас эти якоря не ведут ни к каким выдуманным внешним адресам. Кнопки лучше привязать к реальным существующим маршрутам сайта.

## Как редактировать

- Заголовок и подзаголовок: `index.html`, `.ca-hero__intro`.
- Цвета: CSS-переменные `--ca-blue`, `--ca-blue-dark`, `--ca-ink` в начале `styles.css`.
- Фон: встроенный SVG `.ca-showcase__waves`, стили `.ca-showcase__ground`.
- Макет интерфейса: HTML внутри `.ca-app`.
- Содержимое переключаемых вкладок: объект `scenes` в `script.js`.
- Иконки: встроенный SVG, без скачиваемых изображений.

## Адаптивность и доступность

Макет рассчитан на большие мониторы, планшеты и телефоны. На телефонах панель занимает ширину экрана, три карточки можно листать горизонтально. Работают клавиатурное переключение вкладок, раскрытие меню и Escape. Анимация автоматически сокращается при `prefers-reduced-motion`.

**Примечание:** содержимое панели — **демонстрация** процесса, а не подключение к CRM / 1С. Иллюстрация полностью HTML/SVG, поэтому её можно стилизовать и анимировать дальше.
