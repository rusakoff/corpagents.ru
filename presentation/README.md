# PDF-презентация Corp Agents

- `index.html`, `styles.css` и `site-theme.css` — редактируемый источник слайдов 16:9. Последний файл переносит цвета и типографику из стилей сайта.
- `corp-agents.pdf` — готовый файл для отправки.
- `slide-copy.md` — текстовая версия всех 13 слайдов.
- `email.md` — короткий текст сопроводительного письма.

Для ручного экспорта откройте `index.html` через локальный HTTP-сервер в Chromium, выберите «Печать → Сохранить как PDF» и включите печать фоновой графики. Размер страницы задан в `styles.css` через `@page`.

В печатной версии мягкие тени заданы через `filter: drop-shadow()`: обычный `box-shadow` при экспорте давал квадратные полупрозрачные блоки.

Презентация предлагает пилот внедрения ИИ для руководителя продаж экспедиторской компании. Маршрут Москва — Казань и заявка на 12 палет приведены только как пример. Показатели и стоимость внедрения нужно определить на данных клиента до запуска пилота.

Классификация типовых обращений расположена перед схемой работы агента, а обработка данных и документов по заказу — после примера разбора заявки. Каналы: почта, мессенджеры (Telegram, МАКС), телефония и формы сайта. Для звонков предусмотрена работа с расшифровками записей. Для пилота предлагается один канал и запросы ставки по одному виду перевозки; остальные потоки рассматриваются при расширении.

Порядок типов обращений по частоте — предварительная оценка для обсуждения, которую нужно проверить на истории клиента. Данные о десятках тысяч звонков в день и 9 из 10 типовых запросов относятся к колл-центру ПЭК. Источник: [Антон Слученков, CFO Russia, 22.06.2026](https://www.cfo-russia.ru/stati/?article=100199). Это отраслевой пример, а не результат проекта Corp Agents.
