# PDF-презентация Corp Agents

- `index.html` и `styles.css` — редактируемый источник слайдов 16:9.
- `corp-agents.pdf` — готовый файл для отправки.
- `slide-copy.md` — текстовая версия всех 11 слайдов.
- `email.md` — короткий текст сопроводительного письма.

Для ручного экспорта откройте `index.html` через локальный HTTP-сервер в Chromium, выберите «Печать → Сохранить как PDF» и включите печать фоновой графики. Размер страницы задан в `styles.css` через `@page`.

В печатной версии мягкие тени заданы через `filter: drop-shadow()`: обычный `box-shadow` при экспорте давал квадратные полупрозрачные блоки.

Презентация предлагает пилот внедрения ИИ для руководителя продаж экспедиторской компании. Маршрут Москва — Казань и заявка на 12 палет приведены только как пример. Показатели и стоимость внедрения нужно определить на данных клиента до запуска пилота.
